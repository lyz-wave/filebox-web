连接私有仓库

这个网页只是界面，本身托管在公开的 GitHub Pages 上；你的文件只存在私有仓库 lyz-wave/filebox 的 inbox/ 里。填一个只授权该仓库的令牌，网页才能读、写它。

怎么生成令牌（大约 1 分钟）
  1. 打开 GitHub → 新建 Fine-grained token；
  2. Resource owner 选 lyz-wave，Repository access 选 Only select repositories，并选中 lyz-wave/filebox；
  3. Repository permissions 里把 Contents 改成 Read and write，其它保持默认；
  4. 点击 Generate token，复制生成的 github_pat_... 粘贴到下面的输入框。

也可以用 classic token：生成 repo 权限的 classic token（权限范围更大，能用但不如 fine-grained 干净）。

      这个小站是怎么工作的

      • 网页只是界面（托管在 GitHub Pages），文件写进你的私有仓库 lyz-wave/filebox；
      • 所有读写都直接请求 api.github.com，令牌只在本浏览器和 GitHub 之间使用，不会发给第三方站点；
      • 电脑端仍然可以用 send.ps1 / recv.ps1，两边共用同一个 inbox/；
      • 网页上传受浏览器内存限制，几十 MB 的文件请用电脑脚本或 Release。
